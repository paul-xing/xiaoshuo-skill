# 叙事结构参考

## 一、英雄之旅12阶段（克里斯托弗·沃格勒）

适合长篇网文，尤其适合玄幻/仙侠/奇幻类。

### 第1阶段：平凡世界（Ordinary World）
主角在故事开始前的日常生活。展示主角的缺陷、不满、渴望。
- 网文对应：穿越/重生前的人生境遇
- 示例：「前世是996社畜，意外穿越到修仙世界」

### 第2阶段：冒险召唤（Call to Adventure）
打破日常的事件。
- 网文对应：金手指降临、穿越事件、意外发现

### 第3阶段：拒绝召唤（Refusal of the Call）
主角犹豫、退缩。
- 网文对应：「我能不能回去？」「这个金手指太弱了吧」

### 第4阶段：遇见导师（Meeting the Mentor）
主角获得指导、装备、知识。
- 网文对应：老爷爷、系统精灵、上古传承

### 第5阶段：跨越门槛（Crossing the Threshold）
主角正式进入新世界，无法回头。
- 网文对应：第一次面对生死考验、签订契约

### 第6阶段：考验、盟友、敌人（Tests, Allies, Enemies）
主角适应新环境，结识伙伴，遭遇敌人。
- 网文对应：宗门入门、组队副本、第一次被追杀

### 第7阶段：深入洞穴（Approach to the Inmost Cave）
接近核心危险，做最后准备。
- 网文对应：进入秘境、突破瓶颈前

### 第8阶段：磨难（Ordeal）
主角面对最大的恐惧，经历死亡与重生（象征或实际）。
- 网文对应：被废丹田、生死大劫、被背叛

### 第9阶段：奖赏（Reward）
战胜磨难后获得奖励。
- 网文对应：突破境界、获得神器、美人倾心

### 第10阶段：返回之路（The Road Back）
带着奖赏回归，但仍有阻碍。
- 网文对应：被追杀、被围剿、更大的阴谋浮现

### 第11阶段：复活重生（Resurrection）
最后、最危险的考验，主角彻底改变。
- 网文对应：最终决战、献祭、终极突破

### 第12阶段：带着宝物归来（Return with the Elixir）
主角带着胜利和成长回归平凡，或开启新篇章。
- 网文对应：称帝/飞升/回归地球

## 二、救猫咪节拍表（布莱克·斯奈德）

适合规划整本书的节奏和爆点分布。

### 15节拍总览

| 节拍 | 网文对应 | 位置（100章为参考） |
|------|---------|-------------------|
| 1. 开场画面 | 主角平凡生活的最后一幕 | 第1章 |
| 2. 主题呈现 | 暗示故事核心命题（某人说出金句） | 第1-3章 |
| 3. 铺垫 | 展示主角的缺陷 | 第1-5章 |
| 4. 催化剂 | 金手指/穿越/意外事件 | 第2-3章 |
| 5. 争论 | 主角犹豫，要不要接受改变 | 第3-5章 |
| 6. 第二幕开始 | 主角做出决定，无法回头 | 第5章 |
| 7. 支线故事B | 感情线、团队线 | 第10章起 |
| 8. 玩闹与开心 | 展示金手指的爽，第一次打脸 | 第5-10章 |
| 9. 中点 | 伪胜利或伪失败，主角获得关键筹码 | 第40-50章 |
| 10. 坏蛋逼近 | 反派反击，主角陷入困境 | 第50-70章 |
| 11. 失去一切 | 主角失去最重要的东西 | 第70-75章 |
| 12. 灵魂黑夜 | 主角最绝望的时刻 | 第75-80章 |
| 13. 第三幕开始 | 主角找到解决方案 | 第80-85章 |
| 14. 终局 | 最终决战 | 第85-95章 |
| 15. 最终画面 | 主角完成蜕变后的最后一幕 | 第100章 |

## 三、LOCK系统 + 三幕结构（詹姆斯·斯科特·贝尔）

适合搭建故事骨架。

### LOCK系统
- **L（Lead）** — 引人注目的主角
- **O（Objective）** — 主角的核心目标
- **C（Confrontation）** — 主角面对的冲突
- **K（Knockout）** — 冲击结尾

### 三幕结构
- **第一幕（25%）** — 引入世界、主角困境、金手指降临
- **第二幕（50%）** — 升级打怪、遭遇更强敌人、中期反转
- **第三幕（25%）** — 终局铺垫、最终决战、收尾

## 四、网文特有技巧

### 爽点金字塔
```
第0层：打脸（最基础，踩人）
第1层：装逼（展示实力，碾压对手）
第2层：逆袭（从低谷爬起来，让看不起自己的人后悔）
第3层：守护（保护重要的人，爆发的力量）
第4层：反杀（在绝境中翻盘，最高级爽点）
```

### 期待感营造
- **短期期待**：本章主角会遇到什么麻烦 → 怎么解决？
- **中期期待**：下个副本/秘境/考试是什么？主角能拿到什么？
- **长期期待**：主角最终能复仇/飞升/成帝吗？

### 黄金三章设计
- **第1章**：建立共情 + 抛出悬念 + 金手指出现
- **第2章**：展示新能力/新身份 + 第一次小冲突
- **第3章**：第一次爽点（打脸/装逼/逃脱） + 章节钩子

### 常见流派核心要点
| 流派 | 核心驱动力 | 忌讳 |
|------|-----------|------|
| 玄幻 | 升级+装逼+奇遇 | 等级体系混乱 |
| 言情 | 情感拉扯+误会+守护 | 女主工具人化 |
| 悬疑 | 信息差+反转+恐惧 | 真相提前泄露 |
| 科幻 | 设定新奇+科技碾压 | 硬伤太多 |
| 都市 | 阶层跨越+逆袭+现实感 | 太悬浮 |

### 伏笔管理三原则
1. **埋必收** — 不是推动主线的细节，不要写进去
2. **间隔合理** — 埋和收之间隔3-10章，别拖太久
3. **收伏笔时制造新伏笔** — 一个真相揭露往往引向更大的秘密
